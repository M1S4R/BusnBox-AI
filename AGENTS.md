# BusNBox AI — Codex Project Instructions

## 1. Project Overview

BusNBox AI is a bus-search platform with an AI-powered chatbot named:

- Ask BnB
- BnB AI

The chatbot UI is inspired by the general interaction style of travel-assistant widgets, but the implementation and design must remain original.

The system allows users to:

- Search available buses
- Provide source, destination, and travel date
- Apply filters such as AC, operator, price, seats, and departure time
- Refine previous searches
- Ask booking-related FAQ questions
- Receive recommendations
- Use follow-up suggestion buttons
- Submit thumbs-up or thumbs-down feedback
